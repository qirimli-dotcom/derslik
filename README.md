# Derslik Çantam — без сервера (GitHub Pages)

Ученики регистрируются в приложении, заявку присылают тебе ссылкой, ты одобряешь. Учебники лежат на GitHub **зашифрованными**: каждый ученик открывает только книги своего класса.

## 1. Репозиторий
1. Старый репозиторий `cantam` (с этапа 1) удали: Settings → в самом низу **Delete this repository**. Или создай новый с другим именем.
2. **New repository** → имя `cantam` → **Public** → Create.
3. Загрузи **всё содержимое этой папки** (вместе с `.nojekyll`): «uploading an existing file» → перетащить → Commit.
   За раз GitHub берёт 100 файлов: сначала всё кроме `pdfjs`, потом папку `pdfjs` (если опять много — `cmaps` частями).
4. Settings → **Pages** → Deploy from a branch → `main` / `(root)` → Save. Через 1–2 минуты будет адрес `https://ЛОГИН.github.io/cantam/`.

## 2. Токен для администратора
GitHub → аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**:
- Expiration: 1 год (потом просто сделаешь новый и вставишь в «Sazlamalar»);
- Repository access: **Only select repositories → cantam**;
- Permissions → Repository permissions → **Contents: Read and write**.
Скопируй токен (`github_pat_…`).

## 3. Первый запуск
Открой сайт → появится экран **Qurulış** → твоё имя, логин, пароль, репо (подставится само) и токен → **Qur**.
Через 1–2 минуты GitHub обновит сайт — всё готово. Токен хранится только в браузере администратора.

## 4. Работа
- **Учебник**: İdare → Derslikler → класс, предмет, PDF (до 95 МБ) → «Derslik qoş». Через ~1 минуту появится у учеников.
- **Ученик**: Qayd ol → заполняет → «Arıza yarat» → «Telegram / WhatsApp ile yiber» → присылает ссылку тебе.
  Ты открываешь ссылку (залогиненным) → İdare → Arızalar → **Tasdıqla**. Через ~1 минуту у ученика откроется полка сама.
- **Забыл пароль**: ученик регистрируется заново с тем же логином, ты одобряешь — старый пароль заменится.
- **Blokla**: ученик удаляется, ключ его класса меняется, учебники перешифровываются. Остальным ученикам новый ключ приходит сам.
- **Oca (учитель)**: в Talebeler поставь роль «Oca» — он видит учебники всех классов.
- **Новый год**: Talebeler → «Sınıfnı keçir».
- **Второе устройство администратора**: войди своим логином, вставь токен в Sazlamalar.

## Важно
- Потерял телефон с токеном — удали токен в GitHub (Settings → Developer settings) и сделай новый.
- Лимиты GitHub Pages: файл до 100 МБ, весь сайт до ~1 ГБ.
- Все надписи — в `strings.js` (отдать носителю языка на проверку).
