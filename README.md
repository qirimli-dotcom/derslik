# Derslik Çantam — этап 1

PWA-библиотека учебников. Работает на iPhone, iPad, Android и компьютере, ставится на экран «Домой», скачанные книги читаются без интернета.

## Залить на GitHub Pages
1. Создай репозиторий (например `cantam`) и загрузи в него **всё содержимое этой папки** (вместе с `.nojekyll`).
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту приложение будет доступно по адресу `https://<логин>.github.io/cantam/`.

## Добавить учебник
1. Положи PDF в папку `books/` (латиница, без пробелов: `5-matematika-1.pdf`).
2. В `books.json` найди нужную книгу и впиши путь в `"file"`:
   `"file": "books/5-matematika-1.pdf"`
3. Новую книгу добавь в `books` по образцу: `grade` — класс, `subject` — код предмета из `subjects`, `part` — часть (или пусто), `author` — автор.
4. Книга `5-numune` с файлом `books/numune.pdf` — тестовая, её можно удалить.

PDF больше 100 МБ GitHub не примет — такие сожмём или вынесем на сервер (этап 3).

## Тексты интерфейса
Все надписи лежат в одном файле `strings.js` — его и отдаём на проверку носителю языка.

## Обновление у пользователей
После изменения файлов приложения (не книг) увеличь версию в первой строке `sw.js`: `cantam-v1` → `cantam-v2`.
