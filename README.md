# Derslik Çantam — GitHub Pages, без сервера

- `https://ЛОГИН.github.io/cantam/` — приложение для учеников и учителей: вход, регистрация, полка, чтение.
- `https://ЛОГИН.github.io/cantam/admin/` — **кабинет администратора**: заявки, ученики, учебники, настройки.

Учебники хранятся на GitHub зашифрованными. Каждый открывает только книги своего класса, учитель — все.

## 1. Репозиторий
1. Старый `cantam` удали: Settings → внизу **Delete this repository**.
2. **New repository** → `cantam` → **Public** → Create.
3. Загрузи **всё содержимое этой папки** (вместе с `.nojekyll`, `admin` и `data`).
   За раз GitHub берёт 100 файлов: сначала всё кроме `pdfjs`, потом папку `pdfjs`.
4. Settings → **Pages** → Deploy from a branch → `main` / `(root)` → Save.

## 2. Токен
GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token:
Repository access — **Only select repositories → cantam**; Permissions → **Contents: Read and write**; срок — 1 год.

## 3. Первый вход в кабинет — сразу после загрузки
Открой `…/cantam/admin/` → логин `admin` и временный пароль (он в чате, в файлах его нет).
Откроется **İlk kiriş**: своё имя, свой логин, новый пароль, токен → Saqla.
В этот момент все ключи создаются заново, и временный пароль перестаёт что-либо открывать.

## 4. Работа
- **Учебник**: кабинет → Derslikler → класс, предмет, PDF (до 95 МБ). Через ~1 минуту у учеников.
- **Ученик / учитель**: на главной «Hesabıñız yoqmı? Qayd ol» → форма → «Arıza yarat» → отправляет тебе ссылку.
  Ты открываешь ссылку → кабинет → Arızalar → **Tasdıqla**. Через ~1 минуту у него откроется полка.
- **Забыл пароль**: регистрируется заново с тем же логином, ты одобряешь.
- **Blokla**: удаляет ученика и меняет ключ класса. **Sil**: просто удаляет (например, выпускников).
- **Новый год**: Talebeler → «Sınıfnı keçir».
- **Свой пароль**: кабинет → Sazlamalar → Parolnı deñiştir.
- **Читать самому**: на главной войди тем же логином и паролем — видны все классы.
- **Второе устройство**: войди в кабинет своим логином и вставь токен в Sazlamalar.

## Важно
- Потерял устройство с токеном — удали токен в GitHub и сделай новый.
- Лимиты GitHub Pages: файл до 100 МБ, весь сайт до ~1 ГБ.
- Все надписи — в `strings.js` (отдать носителю языка на проверку).
